## Cross-cutting / product shape

- [ ] **XC.1 Primary IDE route** — Treat `/workspace` as canonical; demote `/project` and `/editor` to redirects or merged panels (duplicate tree, search, editor).
- [ ] **XC.2 Workspace lifecycle helper** — One function: `setProjectPath` + `api.agentSetWorkspace` + index rebuild; fix `WorkspaceSwitcher` (often skips `agentSetWorkspace`).
- [ ] **XC.3 Invalidate agent caches on workspace change** — Clear `ToolState.sem_index`, repo graph, and related maps on `agent_set_workspace` / watcher root change (stale semantic search).
- [ ] **XC.4 Unify semantic search stacks** — Today: `commands/index.rs` keyword backend, `tools.rs` `semantic_search_codebase` TF-IDF walk, `rag.rs` hashed n-grams; converge on `SearchIndex` + optional `SemanticSearchBackend` embedder.
- [ ] **XC.5 Wire LSP diagnostics into agent `read_lints`** — Editor + `verify.rs` use `LspManager`; `read_lints` tool uses heuristics only.
- [ ] **XC.6 Local model tool protocol** — Local GGUF uses markdown `<execute_tool>` only; no native tool channel (`engine.rs`); document limits vs remote `tools` + `tool_choice`.
- [ ] **XC.7 Persist secrets consistently** — Remote/HF tokens memory-only (`enhancement.txt` P4.2); OS keychain or backend-only vault for `hf_` + provider keys.
- [ ] **XC.8 Help + shortcuts drift** — `HelpPage` / `GlobalShortcuts` Ctrl+1–5 omit Workspace, Security, Logs, Hub; align with `Sidebar` routes.
- [ ] **XC.9 MCP visibility in chat** — Settings probe works; composer/status should show enabled MCP servers + tool count (`enhancement.txt` P3.3).
- [ ] **XC.10 API server automation gaps** — `api_server.rs`: no SSE for `agent://*` events, no cancel endpoint, no auth on loopback (document threat model).
