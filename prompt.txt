**Competitors:** index/grep ready when project opens.

**Backend (`src-tauri`):**
- [ ] Optional `workspace_on_open(root)` OR ensure `agent_set_workspace` triggers debounced `index_rebuild` when workspace changes.
- [ ] Emit index progress via `workspace://file-changed` extension or `index://progress` after rebuild.

**Frontend (`ui/`):**
- [ ] `useWorkspaceLifecycle` (or extend `useShell.setProjectPath`): `agentSetWorkspace` → `indexRebuild` → `startFileWatcher`; on clear → `stopFileWatcher`.
- [ ] Use from `WorkspacePage`, `FileEditorPage`, folder pickers — **not only** `ProjectPage.tsx`.

## P1 — Agent depth (Claude Code + Cursor)

### P1.1 Subagent observability
**Backend:** `subagent.rs`, `orchestrator.rs`, `agent/mod.rs`.

- [ ] Emit `agent://subagent-run`: `{ parentSessionId, childId, profile, status, summary, durationMs }`.
- [ ] Pool busy (`leased_workers`) → structured tool error + optional UI banner.

**Frontend:** `AgentTimeline.tsx`, `useAgentStream.ts`.

- [ ] Nested subagent cards; link to activity/session tail.

### P1.2 Verify-after-edit loop
- [ ] `.ai/verify.json`: `{ "command", "cwd", "timeoutSecs" }`.
- [ ] After `apply_edits` when `verify: true`: run command + `lsp_diagnostics` on touched files; emit `agent://verify-result`.
- [ ] One bounded self-heal on failure (`MAX_VERIFY_PASSES`).

**Frontend:** toast + activity; optional Re-run verify in edit panel.

### P1.3 Ask mode hardening
- [ ] Setting: Ask uses `stream_inference` + context snapshot OR `maxSteps: 0` flag — document in Help.
- [ ] Orchestrator: reject mutating tools when `agent_mode == "ask"`.
- [ ] Hard block Agent send when local model below `isAgentCapableLocalModel` threshold (warn exists — add disable or force Ask).

### P1.4 Background tasks & parallel sessions
**Backend:**
- [ ] `background_task_output(taskId, tail?)` + ring buffer in `background.rs`.

**Frontend:**
- [ ] Timeline pill → output drawer; **New agent** while one runs (bg or separate session).
- [ ] Steer/stop on foreground session only.

### P1.5 Session power UX
- [ ] **Fork from message:** `sessionFork(..., forkTurnId: message.turnId, ...)`.
- [ ] **Transcript search:** index session JSONL; Command palette / History search.
- [ ] **Attachments panel:** `agentListAttachments`, detach, file picker in workspace sidebar.

### P1.6 Composer / stream toolbar (reliability)
- [ ] Context meter + trim toast (mostly done — verify on all routes).
- [ ] Stop | Steer | Run in background (mostly done — verify no duplicate listeners).
- [ ] Settings: `maxSteps`, `tokenBudget`, `verify`, `decompose` (mostly in Settings — expose quick strip in composer if missing).
